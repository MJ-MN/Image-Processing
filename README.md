# Image Processing
Image Processing is an application for applying filters on images using multithreading developed by C++.
## Tutorial
### Building
1. Open a new terminal console
2. Create a new destination folder at a place of your choice e.g. at `~/git`: `mkdir $HOME/git`
3. Change to this directory: `cd ~/git`
4. Fetch the project source files by running `git clone https://github.com/MJ-MN/Image-Processing.git`
1. Change into the project source directory: `cd Image-Processing`
2. Run `make clean`
3. Run `make all` to compile and build bin file.
### How to Run
1. Open a terminal and run `bin/ImageProcessor.out <file.bmp>` to run the application.
